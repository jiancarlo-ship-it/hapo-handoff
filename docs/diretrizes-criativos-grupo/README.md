# Diretrizes de Criativos (Grupo) — Guia de Uso

Regras e referências **compartilhadas** para geração de criativos das empresas do grupo Hapo.
O contexto e a identidade visual de cada empresa vivem na pasta raiz dela (ex.: `../Goalfy/Contexto e Identidade/`), não aqui — esta pasta guarda só o que vale para todas.

---

## Como gerar um criativo

### 1. Roteiro para Reel / Vídeo Ad

Fale para o projeto:

> "Crie um roteiro de reel para [Goalfy / Hapo Educação] com o seguinte ângulo: [sua ideia]"

O projeto vai usar a skill **reels-roteiros** combinada com o CONTEXTO da empresa e as DIRETRIZES gerais.

**Exemplo:**
> "Crie um roteiro de reel para Goalfy focando em reativação de carteira para distribuidores de alimentos."

---

### 2. Criativo Estático ou Carrossel (copy + estrutura)

Fale para o projeto:

> "Crie copy para um criativo estático de [Goalfy / Hapo Educação] com objetivo de [geração de lead / retargeting / prova social] e o ângulo [sua ideia]"

O projeto vai usar a skill **hapo-campaign-narrative** combinada com o CONTEXTO da empresa.

**Exemplo:**
> "Crie copy para um carrossel da Hapo Educação explicando o que o aluno sai com depois da imersão."

---

### 3. Narrativa completa de campanha

Para campanhas com múltiplos criativos e mensagem central:

> "Crie uma narrativa de campanha para [empresa] focada em [vertical / objetivo] com [número] de peças"

## Filtro de qualidade (vale para tudo)

Antes de aprovar qualquer peça, responder:

1. Um diretor sênior de empresa estabelecida levaria isso a sério?
2. Está mostrando IA em ação, ou só prometendo resultado?
3. Usa o vocabulário do mercado de quem vai ler (verticalizado)?
4. Dá pra cortar palavra sem perder sentido?

Se qualquer resposta for "não" — reescreve.

---

## Itens pendentes de preenchimento

Os arquivos de IDENTIDADE_VISUAL de cada empresa têm campos marcados com ⚠️ PREENCHER.
São informações que precisam vir do time de design (Aline):

- Hex codes da paleta oficial de cada marca
- Fontes tipográficas oficiais
- Links para arquivos de logo (PNG/SVG em versões light/dark)

Sem essas informações, os criativos estáticos e de vídeo podem ser escritos mas não finalizados visualmente com precisão.
