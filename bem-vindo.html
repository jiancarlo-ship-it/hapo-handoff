Instruções de uso

Como usar cada coisa

Você não precisa rodar comando nenhum manualmente — fale em português normal com o Claude Code dentro da pasta certa. Os exemplos abaixo são só ponto de partida.

1

Gerar uma arte de anúncio

Clone ad-art-chatgpt-pipeline e goalfy-brand-system como pastas irmãs (uma do lado da outra), abra o Claude Code dentro de ad-art-chatgpt-pipeline, e diga:

"Quero gerar uma arte pra Goalfy sobre [assunto], formato Feed."

O Claude já usa a identidade visual da Goalfy pronta (paleta, logo, fonte) e conduz o resto: referência visual, headline, geração no ChatGPT, acabamento. Único pré-requisito: conta paga no ChatGPT com geração de imagem.

2

Escrever legenda ou brief de arte

Dentro deste repositório (ou com as skills copiadas para ~/.claude/skills/), diga:

"Monta o brief de arte pra essa narrativa: [descrição]."
"Escreve a legenda desse anúncio pra Hapo Educação, sobre [tema]."
3

Mexer em campanhas do Meta Ads

Com a skill meta-ads-hapo instalada e o token configurado (o Claude pede na hora se faltar), diga:

"Lista as campanhas ativas da conta da Goalfy."
"Pausa a campanha [nome] e me mostra o motivo de performance."
4

Ver métricas e o funil comercial

Só abrir o dashboard ao vivo, sem pedir nada a ninguém — ele já busca os dados reais das 3 contas Meta Ads e do Goalfy CRM. Se quiser editar ou adicionar algo novo lá, peça ao Claude Code dentro do repo hapo-marketing-dashboard.

5

Conferir a identidade visual antes de criar algo

Abra brand-systems/grupo-hapo-marca-mae/brand-system-hapo.html (Hapo/Assessoria/Educação) ou brand-system-goalfy.html no repositório da Goalfy — cor, tipografia e componentes reais, extraídos direto dos sites ao vivo.
